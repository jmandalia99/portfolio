# jinalmandalia.com

Personal website of Jinal Mandalia — React + Tailwind, hosted on GitHub Pages.

## Edit
- Site text: `src/content.js` (`**double stars**` = bold)
- Chat answers: `src/chatKnowledge.js`
- Photos: `public/images/`, resume: `public/resume.pdf` (keep the file names)

## Publish
```bash
npm install      # first time only
npm start        # preview at http://localhost:3000
npm run deploy   # build and publish
git add . && git commit -m "update" && git push
```
`public/CNAME` keeps the custom domain connected — don't delete it.
