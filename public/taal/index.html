Building blocks · anga

Three parts make every tala

A tala is spelled with the hand. Every one of the seven talas is just a sequence of these three units — and only the Laghu changes length.

I

Laghu

A clap, then finger-counts. Its length equals the jaati (3 – 9).

clap + (jaati − 1) fingers
O

Drutam

A clap, then a wave — palm flipped up. Always two beats.

clap + wave = 2
U

Anudrutam

A single clap. Always one beat.

clap = 1

The key distinction · jaati vs gati

Same names, different jobs

Both use the same five names — Tisra to Sankeerna — and that is exactly why they confuse. But one shapes the cycle; the other fills each beat.

Jaati — the structure

How many boxes

Sets the Laghu length, so it decides how many beats are in the row. Change the jaati and the whole cycle grows or shrinks.

Gati / Nadai — the texture

What's inside each box

Subdivides every beat into equal pulses. The number of boxes never changes — only how densely each one is filled.

↑ tisra gati = 3 pulses per box

In one line: Jaati sets the shape — how many beats. Gati sets the sollukattu flavour — which pattern colours the beats (Ta Ki Ta vs Ta Ka Dhi Mi …). The three speeds set the density — one, two, or four syllables per beat, flowing across the cycle and returning on sam.

Concept · trikaala

What "three speeds" means

Your hand keeps the same tala at the same tempo. What changes is how many syllables flow through each beat — doubling each speed. Example: chatusra gati.

FIRST SPEED
Prathama

One syllable per beat.

Ta · Ka · Dhi · Mi
SECOND SPEED
Dvitiya

Two per beat, flowing on.

TaKa · DhiMi · TaKa · DhiMi
THIRD SPEED
Tritiya

Four per beat — full and alive.

TaKaDhiMi · ×4
Three dials, never confused: the jaati sets how many beats, the gati sets the subdivision inside a beat, and the speed doubles how fast you fill. Adi stays 8 beats through all of them — everything else happens inside that frame.
